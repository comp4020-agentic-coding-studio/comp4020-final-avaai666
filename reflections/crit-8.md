# Crit 8 reflection

## What was the breakthrough that moved the work forward?

A short simulation. My first design sounded right. "Only a room can empty the pond." I wrote that line and believed it. Then I ran the numbers. One person could empty the pond in 12 minutes. A pond with 0.4 fish grew back. Two promises in my design contradicted each other. Nothing was built yet, so throwing them away was cheap.

After that I changed how I work. Every claim in the design is now either a test or an assumption listed for a playtest. The parameters came from the simulation, not from what sounded good.

## What did this work change about who I want to be as a software developer?

I used to read "all tests pass" as "it works". This week the agent said every check was green, and in the same message said the page script had never run in a browser. Green only covers the layer the tests can see.

I want to be the developer who asks which layer a "done" is about, and goes and looks at the layer nobody checked. That includes my own checks. One bug I found was my own test's mistake.
